# 开启“邮箱验证码登录”（负责人操作，约 15 分钟）

代码已经写好：设好下面两个 Worker 密钥后，登录框里会出现“邮箱验证码登录”（没有账号的邮箱会自动注册）和“忘了密码？用邮箱验证码登录”，账号面板里会出现“添加邮箱 / 验证邮箱 / 更换邮箱”。没设之前这些都不显示，别的登录方式照常。

## 不花钱，也不会被扣钱

- 发信用 Resend 的免费套餐：每月 3000 封、每天 100 封。免费套餐用完就停发，不会自动升级，不会产生超额费用。**注册时不要绑信用卡**，没绑卡就不可能扣钱。
- 网站自己先设了更低的上限：同一个邮箱每分钟 1 封、每小时 5 封；全站每天最多 80 封（可以用 Worker 变量 `EMAIL_DAILY_LIMIT` 改）。到了上限就不发，页面提示“今天的验证码已经发完了，请明天再试，或者用密码、Google 登录”。
- 最坏的情况：有人捣乱时当天验证码发不出去，第二天自动恢复。密码登录、Google 登录和游客都不受影响。

## 步骤

1. 打开 <https://resend.com>，注册账号，用免费套餐（Free），**不要绑信用卡**。
2. 左侧 **Domains** → **Add Domain**，填你的域名（例如 `example.com`）。
   - 域名在 Cloudflare 的话，Resend 可以一键把 DNS 记录加到 Cloudflare；否则按它列出的几条记录（DKIM、SPF 等）手动加到 Cloudflare 的 DNS 里。
   - 这些记录在子域名上，不影响你现在用 Cloudflare 收邮件。
   - 加好后点 **Verify**，状态变成 Verified 即可（通常几分钟）。
3. 左侧 **API Keys** → **Create API Key**：名称随意，权限选 **Sending access**，Domain 选刚才的域名。Key 只显示一次，复制下来，不要发到聊天里或提交进仓库。
4. 在项目目录运行这两条命令，按提示粘贴：

   ```powershell
   npx wrangler secret put RESEND_API_KEY
   npx wrangler secret put EMAIL_FROM
   ```

   - `RESEND_API_KEY`：上一步复制的 Key。
   - `EMAIL_FROM`：发件人，格式是 `Topology Go <noreply@你的域名>`（`noreply` 可以换成任何名字，域名必须是第 2 步验证过的那个）。

设完立即生效，不用重新发布。打开网站 → 右上角“登录”，应该能看到“邮箱验证码登录”。

## 用户怎么用

- **忘了密码**：登录框里点“忘了密码？用邮箱验证码登录” → 填账号的邮箱 → 收到 6 位数验证码（10 分钟内有效）→ 登录。登录后直接停在“设置新密码”，不用输旧密码。
- **平时**：也可以每次都用验证码登录，不用密码；没有账号的邮箱第一次登录就自动注册一个，用户名从邮箱生成，可以在账号设置里改。
- **改密码**：账号设置里“设置新密码”，登录了就能直接设，不用输旧密码。改好后，其他设备上的登录会退出。
- **邮箱**：注册时没填的，可以在账号面板里“添加邮箱”；填了但没验证的，点“验证邮箱”。都是收一个验证码确认。
- 账号上没验证过的邮箱收不到登录验证码（防止有人拿别人的邮箱占号；迁移 0004 之后已经没有这种邮箱）。
